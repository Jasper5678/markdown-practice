## How to Play Football

1. Divide the players into two teams.
2. Choose a goalkeeper for each team.
3. Start the match by kicking the ball.
4. Try to score goals in the opponent's goal.
5. The team with more goals wins.

## Football Positions

| Position | Main Job |
| --- | --- |
| Goalkeeper | Stops the ball from entering the goal |
| Defender | Protects the team's goal |
| Midfielder | Helps in attack and defence |
| Forward | Tries to score goals |

## Simple Football Code
